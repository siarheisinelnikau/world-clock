# World Clock 0.5.3

Reveal desktop clocks directly from the tray while keeping the right-click menu independent.

## Fixed

- Left-click the tray icon to show existing desktop clocks above ordinary application windows. Hidden and minimized clocks are restored, repeated clicks keep them visible, and Settings stays closed. If no clocks have **On desktop** enabled, nothing opens.
- Right-click opens the usual native menu without showing or raising the clocks. The menu now uses a separate hidden owner instead of activating the clock panel.
- Revealing clocks preserves the saved **Always on top** preference and mouse click-through behavior. Settings, Updates, and Quit remain available from the menu.

## Verification

- Eighteen isolated checks exercise the production tray callback, actual native window stacking, repeated activation, hidden/covered/minimized states, no selected desktop clocks, and the real native context menu.
- Settled visible, hidden, minimized, and restored samples record no repeated rasterization or presentation. Physical clicks through Explorer's tray, mixed-monitor interaction, GPU timing, and input latency are not covered by these checks.

## Download

Download **WorldClock-v0.5.3.exe** for 64-bit Windows 10/11. This is a portable executable; no installation or extra runtime is required. **SHA256SUMS.txt** contains its SHA-256 checksum.

Saved clocks and preferences are retained. Existing users can download and install this update from **Updates** in Settings or the tray menu. When replacing the portable EXE manually, quit the old tray instance before starting the new one.
